# Meridian mock: credits

Placeholder footage for the launch film. Meridian, its carriers, consignees and people are invented.
Hub names are real places.

- Map geometry: Natural Earth 1:50m country outlines, public domain (naturalearthdata.com), through the
  world-atlas 2.0.2 package (cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-50m.json), projected to
  `site/geo.js`.
- Type: Inter and JetBrains Mono, SIL Open Font License, loaded from Google Fonts.
- Charts: `site/charts.js`, from the tasteskill assets.
- Photographs: none; the screen does not depend on a photograph.

- full-nodots.png (film/public/mock/meridian/full-nodots.jpg, used by Dash): the same page from `site-nodots/` (the film's no-dots version): lanes drawn as solid lines instead of load dots, no hub markers or Rotterdam ring, line keys in the legend, lane progress as a bar fill. Same layout and size as full.png (1600 x 1293 CSS px at DPR 1.5, headless Edge `--screenshot`).
