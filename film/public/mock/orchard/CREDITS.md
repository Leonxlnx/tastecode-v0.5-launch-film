# Orchard mock: credits

Placeholder footage for the launch film. Orchard, Fernbrook Software and every customer, person and figure are fictional sample data.

- Photographs: none. A dashboard has no slot for one, so no images were fetched.
- Typeface: DM Sans, SIL Open Font License, loaded from Google Fonts.
- Mark and icons: drawn by hand as inline SVG for this mock.
- Charts: inline SVG rendered from the dataset in `site/app.js`.

- full-nodots.png (film/public/mock/orchard/full-nodots.jpg, used by Dash): the same page from `site-nodots/` (the film's no-dots version): the MRR line has no end marker. Same layout and size as full.png (1600 x 1420 CSS px at DPR 1.5, headless Edge `--screenshot`).
